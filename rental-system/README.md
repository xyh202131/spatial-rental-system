# 空间智能租房系统

这是《20260912浙大群核实验》的本地双端合并版。动态封面作为统一入口，房东端保留原有采集、复查、模型导入和家具试摆，租客端通过已发布的房源查看三维空间、试摆家具并提交看房预约。

## 启动

在本目录使用 Node.js 24 或更高版本运行。

```powershell
npm ci
npm run build
npm start
```

克隆后可以直接启动封面、房东端和租客端。服务启动时会在 `.data/demo-v1/` 生成合成客厅和卧室，供两房发布与预约联调使用。体验原材料包和家具试摆时，可从原工作区复制 `materials/`、`outputs/aholo/`，以及 `public/cover/assets/` 下的 `scene-data.js` 和 `scene.bundle.js`。房东也可以导入自己的 SPZ 或 PLY。

- [系统封面](http://127.0.0.1:4327/cover/)
- [房东采集台](http://127.0.0.1:4327/landlord)
- [租客看房](http://127.0.0.1:4327/tenant)

首次启动会生成房东账号密码，保存在本机 `.data/local-login.txt`，终端输出该文件位置。服务默认只监听回环地址，SQLite 和发布快照也存放在本系统自己的 `.data/`。

## 用材料包跑通双端

只有源码时，在房东端选择「合成演示 · 客厅」作为主空间，并加入「合成演示 · 卧室」。可从下方第 2 步开始体验发布和预约。

1. 打开租客端的「云谷魔搭会议室」，可立即查看材料包的三维模型、添加盆栽和蓝猫、保存本浏览器的试摆布局。
2. 登录房东端。在「用户中心」用三张流程示例完成模拟核验。
3. 在「房源与预约」选择主空间，按需加入其他房间。逐房间确认入口视角、画面和公开内容。可选一张有发布授权的照片，租客可先看照片，再打开三维。对部分采集的空间填写未采集区域。
4. 用途选择「联调房源」后发布。默认采用预约时段，在同一页为房源开放 30 分钟的未来时段。选择「展示样例」时，租客只能浏览。账号的核验仍是模拟，本地发布面向演示。
5. 用另一个浏览器窗口打开租客端，选时段并提交预约。房东确认或婉拒，租客可在提交预约的浏览器里通过回执取消或改期。房源下架会取消未来预约，已有回执保留状态。

## 从房间照片重建并发布

1. 在房东端新建采集，选择「重建照片」，点击「上传房间照片」，选取同一房间至少 20 张有相邻重叠的 JPG、PNG 或 WebP。可切换为「检查近照」单独上传对照照片。
2. 等待素材保存后进入复查。页面和下载报告会记录图片来自文件上传。检查并回看素材后，勾选人工复核确认。
3. 服务端配置 `AHOLO_API_KEY` 后，可在成果页提交 Aholo 空间重建。停留在成果页时会同步素材上传和平台进度。若在发出创建请求前上传失败，可以重传同一批素材。创建结果待核对时，请先到 Aholo 查询原任务。现有入口使用极速档，创建会消耗平台额度。
4. 重建成功后查看三维预览，点击「发布此空间」并填写房源信息。发布成功后在另一个浏览器打开「租客视角」，查看模型并提交预约。

## 素材和实现

| 接入材料 | 本地位置 | 用途 |
| --- | --- | --- |
| `yungu-meeting-lite.ply` | `outputs/aholo/ARCHIVE20260912/room.ply` | 材料包的 99,650 点高斯场景，可从房东端预览和发布 |
| 盆栽、蓝猫 GLB | `materials/furniture/` | 房东与租客共用的家具试摆资产 |
| 同两件家具的 USDZ | `materials/furniture/` | 租客端下载的原始 AR 文件 |
| `catalog.json` | `materials/archive-catalog.json` | 保留包内房间、家具和参考尺寸来源 |
| 客厅剖视动态封面 | `public/cover/` | 使用最初生成的主视觉，提供房东、租客和 Aholo 三维样例入口 |

服务沿用房东端原有账号、相机、采集复查、Aholo 重建适配和三维查看器。发布时复制一份经校验的模型快照，租客只能通过公开房源读取该快照。账号、原始采集素材和预约联系方式受房东权限保护。租客试摆布局按房源和模型版本存在自己的浏览器，房东布局仍保存在原工作台中。

已有房间和本地试摆可以在补齐相应素材后体验。新建 Aholo 重建任务需要在本机 `.env` 中配置 `AHOLO_API_KEY`，可参考 [.env.example](.env.example)，并由房东在采集成果页确认提交。本地演示使用模拟证件核验、预约回执和示意比例。真实机构核验、签约支付和银行托管属于材料报告中的方案，当前未接入。iOS 真机 AR 也未验收。

## 检查

```powershell
npm run check
npm run build
npm test
npm run test:e2e
```

自动化测试使用临时数据库、测试相机和云端接口桩。干净克隆可使用合成场景验证多房间发布、照片回退和预约，原材料包及家具试摆用例在补齐相应文件后运行。运行数据备份应覆盖 `.data/`，包含已发布模型、照片和预约记录。

2026-11-12 本地复核通过语法检查、生产构建、33 项 Node 测试和 16 项 Edge 浏览器测试。测试包括材料包模型发布、租客试摆与恢复、预约确认和下架。恢复的动态封面另外检查了桌面与手机尺寸、业务导航和三维样例开关。
