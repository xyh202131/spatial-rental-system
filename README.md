# 空间智能学习与实验工程

**双端系统已接入实验材料。** 动态封面、房东采集台和租客看房共用一个本地服务。启动与体验步骤见 [空间智能租房系统](rental-system/README.md)。

从《训前学习资料》出发，建立可追溯的资料库，按“理解概念 → 检查三维资产 → 对比重建 → 验证空间关系”的顺序开展学习。

仓库中的应用源码位于 `rental-system/`。以下保留 2026-09-11 的资料研究与初始化记录，其中的学习资料、实验台账和原始素材位于本地工作区。

## 从这里开始

1. 阅读本地 `docs/分析与总结.md`，了解空间智能、群核产品体系及项目选择。
2. 按本地 `docs/学习路线.md` 推进，先做 E001 资产检查，再进入云端重建。
3. 在本地 `knowledge/index.md` 查原始链接、抓取范围与缺口。
4. 使用本地 `experiments/README.md` 建立记录，接入接口前阅读 `docs/开发接入备忘.md`。

## 工程结构

```text
训前学习资料.md             用户原始材料，保留原文
docs/                      分析、路线、接入备忘、初始化验收
knowledge/                 资料索引与 sources.json 来源台账
experiments/
  plans/                   三个递进实验的可执行计划
  templates/               实验记录、采集记录、空间问答标注模板
  ledger.md                实验状态与证据入口
data/raw/                  后续采集或获准下载的原始数据，默认忽略
data/samples/              示例元数据；目前不含真实三维资产
outputs/                   后续实验产物，默认忽略
.firecrawl/                按域名与路径保存的网页快照，默认忽略
```

## 使用方式

用编辑器打开本目录并预览 Markdown 即可。开始某个实验时，将对应模板复制到新的实验记录目录，先填数据来源、变量、验收规则和预算，再开始操作。

`.firecrawl/` 快照保留在本机；Git 中适合保存的是整理后的文档与来源台账。日后只复制 Git 文件时，原始抓取快照不会自动随仓库迁移。
